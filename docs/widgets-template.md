# Шаблон "widgets" (как у @zenxx_py): инструкция

Что копируем: только формат (структуру и приёмы анимации). Вся графика и тексты наши; автор на плашке: `автор: vybex` (`config.json → handle`).

## Композиция (1080x1920)
- Интерфейс «телефона» лежит в **квадрате 1080x1080 по центру** (y 420..1500). Сверху и снизу чёрные поля (зоны интерфейса TikTok).
- В верхнем чёрном поле первые ~2 с **хук-вопрос** белым с розовым свечением (`spec.hook`, до 36 знаков, ЗАГЛАВНЫМИ, вопрос про смысл: «ЛЮБОВЬ ИЛИ БАБКИ?»).
- Интро 1.2 с: иконка-обложка, пунктирное кольцо, конфетти, `автор: vybex`, артист — трек.
- Дальше: остров-плеер (эквалайзер по битам) → одна карточка на строку/фразу → финал «Слушай полностью».
- Внизу квадрата: плашка автора, «Артист — Трек», прогресс-бар с таймером.

## Темп
- Клип 25–40 с, карточка меняется каждые **2–3.5 с** (одна карточка на 1–2 строки; никогда не 5 строк на карточку).
- Карточка держится до старта следующей (пауза в вокале не оставляет пустой экран).

## Анимация (что делает каждая карточка)
- Появление: снизу с лёгким 3D-наклоном и размытием (0.38 с), уход вверх с размытием (0.22 с), конфетти-вспышка.
- **Субтитров нет**: текст строки на карточке не показывается, смысл несёт картинка. Под картинкой короткая подпись `cap` (до 26 знаков, своими словами: статус, вопрос; пишет Claude, у каждой карточки). Подпись появляется через 0.55 с после карточки. Если ни у одной карточки ролика нет `cap` (откат на автоподбор), строка подписи не резервируется.
- Картинка живёт **по словам**: событие на ~10%, ~30%, ~65% длительности карточки (загорается «Я», летит сердце, загорается «Ты»).
- Остров превращается в уведомление (`notify`), у route/thermo/alert/target оно включено по умолчанию (`"notify": false` отключает).

## Виды карточек (`spec.widgets[].kind`)
Общие поля: `lines:[i,j]` (индексы строк внутри фрагмента), `app` (название приложения), `cat` (подпись под названием), `icon` (цвет), `label`.

| kind | когда брать (смысл строки) | поля |
|---|---|---|
| `pair` | двое, «я и ты», отношения | `a`, `b`, `label` |
| `pulse` | любовь, сердце, волнение, страсть | `from`, `to` (уд/мин), `unit`, `label` |
| `route` | путь, дорога, «куда-то», расстояние между людьми | `from`, `to` (названия мест), |
| `venn` | «вместе», общее, совпадение | `from`, `to` (×1→×N), `label` |
| `ring` | счастье, процент, «наполненность» | `from`, `to` (%), `label` |
| `thermo` | боль, болезнь, холод, жар | `from`, `to`, `unit` |
| `alert` | опасность, смерть, угроза, ирония «ну и дела» | `word` |
| `target` | цель, борьба, враг, «попал» | `label` |
| `polaroid` | воспоминания, время, «тогда и сейчас» | `from`, `to` (годы), `label` |
| `versus` | выбор, «ожидание и реальность», «А или Б» | `art`, `label`, `art2`, `label2` |
| `counter` | цифры, деньги, «сколько» (с картинкой `art`) | `from`, `to`, `unit`, `label`, `button`, `fill` |
| `search` | вопрос в строке | `query`, `result`, `sub` |
| `chat` | диалог, реплики | `msgs:[{from:"her"/"me", text}]` |
| `dots` | «один из миллиардов», толпа и «я» | `from`, `to`, `chosen`, `label` |
| `camera` | «смотри на меня», взгляд, фокус | `focus`, `bubble`, `zoom` |
| `scene` | атмосфера (картинка `art`) | `art`, `big`, `emblem`, `pill` |

`art` (картинки): sunset, map, pulse, clock, rain, moon, eye, city, coins.

## Как подбирать картинки к смыслу
1. Прочитать строки фрагмента из `analysis-<n>.json` (текст только из whisper, ничего не выдумывать).
2. Для каждой строки/пары строк назвать, **что показывает смысл буквально** (кто, куда, сколько, как меняется) и взять вид из таблицы, у которого есть изменение во времени (счётчик, маршрут, сближение, заполнение).
3. Не повторять один вид подряд; подписи короткие (≤ 12–22 знаков), без выдуманных фактов о песне/артисте.
4. Для неочевидных строк оставить `scene` или не писать виджет: автоподбор по ключевым словам (`render_widgets.AUTO`) заполнит сам.
5. Хук = вопрос, на который отвечает фрагмент.

## Где что лежит
`pipeline/render_widgets.py` (раскладка, хук, интро, слова, переходы), `pipeline/widget_kinds.py` (новые виды карточек), `pipeline/qa.py` (проверка полей spec), `tests/test_widget_kinds.py`.

## Движение (по полному разбору эталона, 10 кадров/с)
- **Карточка**: плавно поворачивается влево-вправо (rotationY ±3–5°, ~2.6 с на сегмент, `sine.inOut`), крупнее на 4% (`CARD_ZOOM`), верхний край всегда ниже острова и уведомлений (y ≥ 168). **Биты не используются нигде**: ни ударов карточки, ни вспышек фона, ни прыжков острова/плашки; уведомление не трясёт карточку. Точки-индикатор = число карточек.
- **Стопка**: старая карточка остаётся позади (масштаб .93, размытие, 0.5 прозрачности ещё 0.6 с), новая наезжает снизу-слева с наклоном.
- **Шарик-связка**: светящийся шарик с хвостом перелетает от ключевого объекта прежней карточки к объекту новой (`ANCH` в render_widgets.py).
- **Уведомления (как у @zenxx_py, разбор «Выпускной»)**: уведомление живёт в самом острове. Музыка в острове гаснет (0.15 с), остров на миг пустой и чуть расширяется (×1.14, 0.3 с), появляются иконка приложения, название, подпись и «сейчас»; через ~1.4 с содержимое гаснет, пустой остров, музыка возвращается. Уведомление приходит с каждой карточкой и **связано с её сюжетом** (`widgets[].notify = {app, text, icon}`; без него `DEFAULT_NOTIFY`/`DEFAULT_TOAST`/`BANNER_POOL`); карточка вибрирует; `"notify": false` отключает.
- **Ничто не стоит**: моргает двоеточие часов, садится батарея, качается нота и эквалайзер острова, вращается аватар в плашке автора, плывёт название, бегут бегунок и время, дрейфуют цветные пятна фона и конфетти, по каждой карточке проходит блик, тело карточки плавает, значок и точка-индикатор пульсируют на битах.
- Конфетти и цветные пятна фона плывут всё время; эквалайзер острова ходит по фиксированным часам, не по музыке.
- **Финал**: последняя карточка схлопывается в шарик, он вырастает в светящийся розовый шар с белым кольцом и конфетти, внизу плашка `автор: vybex`. Без названия и заставки (как у @jusazmjq).
